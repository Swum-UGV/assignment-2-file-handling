# Assignment 2 - MiniBank with File Handling

## Description

This project is an improved version of the MiniBank application using Python file handling.

User data is stored in a text file so the data can be loaded again when the program is restarted.

## Features

- User Registration
- User Login
- Money Transfer
- Money Withdrawal
- Update User Information
- Save User Data to File
- Load User Data from File
- Logout

## Files

- `Assignment2.py` - Main Python program
- `users.txt` - Stores user account data

## Requirements

- Python 3

## How to Run

Open a terminal in the project folder and run:

```bash
python Assignment2.py
```
